# NutriTrack PRO

Calcolatore di calorie e macro (carboidrati, proteine, grassi) dei pasti di ogni giorno.
Capisce se un alimento è pesato crudo o cotto e converte i grammi da solo.

- React + TypeScript + Vite + Tailwind.
- Giorni da mezzanotte a mezzanotte, barra dei giorni + calendario, storico.
- Ricerca prodotti per nome e codice a barre su Open Food Facts (dati ODbL).
- Per ora i dati restano nel browser; login e Supabase nella fase 3.

Comandi: `npm run dev` (sviluppo), `npm test`, `npm run build`, `npm run preview` (porta 5180).
Sul PC parte da sola con l'attività pianificata "NutriTrack PRO locale" (`scripts/avvia-pc.vbs`).

Stato del progetto e prossimi passi: `AIOS_STATE.md` (protocollo AI-OS).
