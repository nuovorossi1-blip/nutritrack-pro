# NutriTrack PRO

Calcolatore di calorie e macro (carboidrati, proteine, grassi) dei pasti della giornata.
Capisce se un alimento e' pesato crudo o cotto e converte i grammi da solo.

- Un solo file: `index.html`, si apre direttamente nel browser.
- I dati restano nel browser (localStorage); backup ed esportazione in JSON.
- Ricerca dei prodotti per codice a barre su OpenFoodFacts.

Stato del progetto e prossimi passi: `AIOS_STATE.md` (protocollo AI-OS).
